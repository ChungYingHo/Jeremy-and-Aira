This project self-hosts an exact-text WOFF2 subset for the homepage poem.
fontTools removed TrueType hinting and legacy gasp/mort tables; the latter
include an invalid legacy gasp table that modern fontTools cannot decode.
All 23 required Unicode code points are present. Glyph outlines are identical
to the official TrueType source. No simplified or alternate-codepoint glyphs
were substituted. Font names are preserved; the CSS family is a local alias.
